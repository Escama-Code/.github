## 🚀 Sobre Nós

A **Escama Code** é uma organização voltada para a criação de soluções tecnológicas acessíveis, ferramentas educacionais e bibliotecas open-source. Nosso foco principal abrange o desenvolvimento de software para robótica, ambientes de desenvolvimento (IDEs) e projetos inovadores para a comunidade.

## 🤝 Como Contribuir

Contribuições são sempre bem-vindas! Se queres ajudar a melhorar as nossas ferramentas:

1. Faz um **Fork** do repositório em que pretendes trabalhar.
2. Cria uma nova *branch* para a tua funcionalidade (`git checkout -b feature/minha-funcionalidade`).
3. Submete as tuas alterações (*commit*) e faz o *push* para a tua *branch*.
4. Abre um **Pull Request** detalhando as mudanças realizadas.

Para reportar problemas ou sugerir novas ideias, utiliza a aba de **Issues** no repositório correspondente.
